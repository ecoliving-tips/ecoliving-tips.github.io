# Swaram

**Free AI-powered chord finder for any song + curated Malayalam Christian devotional chord library.**

Upload any audio file and get instant chord detection powered by AI. Works with any genre, any language, any instrument.

## Features

- **AI Chord Finder** - Upload audio, get chords instantly (any song, any genre)
- **1,000+ Chord Pages** - Auto-generated from AI detection with guitar & keyboard diagrams
- **Malayalam Chord Library** - Hand-curated Syro Malabar Holy Mass & devotional songs
- **Guitar & Keyboard Diagrams** - 221 chord shapes rendered as interactive SVGs
- **Transpose** - Change key with one click, all chords update
- **Auto-Scroll** - Hands-free scrolling during practice
- **PWA / Offline** - Install as app, works without internet
- **Bilingual** - English & Malayalam (i18n)
- **Song Request** - Request chords for any Malayalam devotional song
- **Daily Automated Builds** - New chord pages published automatically via GitHub Actions

## Tech Stack

- Static HTML / CSS / JavaScript (no framework, no bundler)
- Zero npm dependencies
- Node.js build system (`node build.js`)
- GitHub Pages hosting
- Supabase (song requests)
- HuggingFace Spaces (chord detection API)
